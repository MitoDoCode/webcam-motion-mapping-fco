HOW TO RUN:

1. Download every file from repository

2. Install the requirements.
   Install Python if it is not yet installed. Then open a command prompt
   inside the extracted folder (type "cmd" in the folder's address bar and
   press Enter) and run:

       pip install -r requirements.txt

   This installs the required packages: MediaPipe, OpenCV, and NumPy.

3. Check the model files.
   Make sure the .task files are in the same folder as Implementation.py.

4. Run the program.
   Connect a webcam and double-click the run.bat file in the extracted
   folder. On the first run, the script downloads the Full Model, Hand, and
   Face Landmarker model files automatically if they are not already
   present.

5. Use the controls.
   Press q to quit, h to toggle finger tracking, and f to toggle the Face
   Landmarker.
